# README

A Nintendo 2DS/3DS version of The BPD Card Desk (Dr. Daniel J. Fox, 2023), with practical tools and exercises for managing BPD symptoms.

The original 52-card deck was created by Dr. Daniel J. Fox, PhD, a psychologist specialising in personality disorders.

The BPD Card Desk - Daniel J. Fox, PHD, New Harbinger Publications, 2023.

The is an unofficial app and is not affiliated with or endorsed by the author or published. 

Daniel Fox is a specialist in BPD and personality disorders. Please check out his other resources if you've not already:  
[Amazon](https://www.amazon.co.uk/stores/Daniel-Fox/author/B07H8K6ZK6)  
[YouTube](https://www.youtube.com/channel/UC932vfOwTbFni3GRrvVA6IQ)
[www.drdfox.com](http://www.drdfox.com)

## CONTROLS

Touch Screen - Tap category you would like to view  
A - New random activity
Up/Down - Change category  
Left/Right - Browse cards  
X - Favourite/Unfavourite  
Y - View Favourites/All
B - Help/Return to Affirmations
